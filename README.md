# StayAhead

Aplikacja mobilna (React Native + Expo) do planowania rozwoju kariery z mentorem AI, dziennymi zadaniami i roadmapą kompetencji.

## Stack

- Expo SDK 57 + TypeScript
- React Navigation (native stack + bottom tabs)
- NativeWind v4 + Tailwind CSS
- Zustand
- React Native Reanimated

## Start

```bash
npm install
npx expo start
```
